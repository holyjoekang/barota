# 바로타 (barota)

나와 어르신을 위한 큰 글씨 지하철 안내 웹앱입니다.
타는 역과 내리는 역을 고르면 경로를 단계별로 보여주고, 탈 열차가 **몇 분 후 도착하는지** 실시간으로 표시합니다.

배포: https://barota-five.vercel.app/

## 사용 방법

1. 처음 화면에서 **어디로 가시나요?**를 고릅니다.
   - **출근**: 잠실나루 → 판교
   - **퇴근**: 판교 → 잠실나루
   - 평일 오전(05:00~11:59)에는 출근, 오후(12:00~23:59)에는 퇴근에 "지금 추천" 표시가 붙습니다.
   - **다른 경로**: 타는 역과 내리는 역을 입력합니다. 자동완성되고, "서울역"처럼 '역'을 붙여도 됩니다. "⇅ 바꾸기"로 두 역을 맞바꿀 수 있고, 최근 경로 4개가 버튼으로 남습니다.
2. 안내 화면에서 단계별로 큰 글씨 안내를 봅니다. 예: 잠실나루 → 판교 (약 37분 · 환승 1회)
   1. 잠실나루역: 2호선 강남 방면 승차
   2. 강남역 하차: 신분당선으로 환승
   3. 신분당선 승차: 판교 방면
   4. 판교역 하차
3. 승차 단계와 환승 단계에서는 탈 열차의 **다음 열차 / 그다음 열차**가 "N분 후 도착"으로 표시됩니다.
   - 행선지(예: 성수행)와 열차의 현재 위치도 함께 나옵니다.
   - 15초마다 새로 받아오고, 남은 시간은 1초마다 다시 계산합니다.
4. "다른 곳 선택"을 누르면 처음 메뉴로 돌아갑니다.

음성 안내 없이 텍스트로만 안내합니다.

## 구조

| 파일 | 역할 |
|---|---|
| `index.html`, `style.css` | 화면 (시작 메뉴, 큰 글씨 안내, 이동 단계, 실시간 도착 정보) |
| `app.js` | 화면 동작, 단계 안내, 실시간 정보 조회·표시 |
| `route.js` | 경로 계산 (브라우저에서 실행, Node에서도 사용 가능) |
| `data/subway.json` | 수도권 지하철 역 660개와 역 사이 연결 정보 |
| `api/arrivals.js` | Vercel 서버리스 함수. 서울시 실시간 도착정보 API를 대신 호출합니다 |
| `vercel.json` | 함수 설정 (최대 10초) |

### 경로 계산 (`route.js`)

- 가장 빨리 도착하는 경로를 고릅니다(다익스트라 알고리즘). 환승할 때마다 7분(이동 + 평균 대기)을 더해 계산합니다.
- 역 사이 소요 시간은 정차 시간 0.7분에 거리 ÷ 노선별 평균 속도를 더한 **추정치**입니다.
- 급행 전용 구간은 계산에서 뺍니다.

### 실시간 도착 (`api/arrivals.js`)

```
GET /api/arrivals?station=잠실나루&lineId=1002&next=잠실
```

| 파라미터 | 설명 |
|---|---|
| `station` | 타는 역 (끝의 '역'은 생략 가능) |
| `lineId` | 서울시 API 노선 ID (1002 = 2호선, 1077 = 신분당선 등) |
| `next` | 경로상의 다음 역. 열차 정보의 "OO방면"과 같은 열차만 보여줍니다 |

- **응답:** `{ items: [{ destination, seconds, estimated, message, location, status, express, lastTrain, ... }], warnings, updatedAt }`
- **남은 시간 보정:** 서울시가 열차 정보를 받은 시각부터 지금까지 지난 시간만큼 빼서 돌려줍니다.
- **남은 초가 없을 때:** "[N]번째 전역" 같은 위치 정보에서 역 하나당 2분으로 추정하고 `estimated: true`로 표시합니다. 화면에는 "약 N분"으로 나옵니다.
- **출발한 열차:** 이미 이 역을 떠난 열차는 뺍니다.
- **캐시:** 같은 역의 응답은 15초 동안 저장해 두었다가 다시 씁니다.

## 배포 (Vercel)

1. 이 저장소를 Vercel에 연결합니다. 빌드 설정 없이 정적 파일과 `api/` 함수가 그대로 배포됩니다.
2. 환경변수를 설정합니다.
   - `SEOUL_SUBWAY_KEY`: [서울 열린데이터광장](https://data.seoul.go.kr/) 실시간 지하철 인증키 (필수)
   - `ALLOWED_ORIGIN`: CORS 허용 도메인 (선택, 기본값 `*`)
3. 화면은 같은 사이트의 `/api`를 기본으로 호출합니다. 다른 서버를 쓰려면 화면의 ⚙️ 설정에서 주소를 바꿀 수 있습니다.

인증키는 서버 환경변수에만 넣고, 화면 코드에는 절대 넣지 마세요.

## 로컬에서 실행

```bash
npx vercel dev
```

## 제한 사항

- **추정치:** 경로와 소요 시간은 추정치입니다. 실제 탑승·환승은 역의 공식 안내를 우선 확인하세요.
- **실시간 정보 미제공 노선:** 인천 1·2호선, 김포골드라인, 용인·의정부경전철, 인천공항 자기부상철도는 서울시 실시간 API가 정보를 주지 않습니다. 화면에 "실시간 정보 미제공"으로 표시됩니다.
- **역 이름 불일치:** 지도 데이터(OpenStreetMap)의 역 이름이 서울시 API와 다르면 도착 정보가 나오지 않을 수 있습니다. 괄호 안 부기명은 무시하고 비교합니다.
